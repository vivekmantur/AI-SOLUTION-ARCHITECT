# Pattern: Centralized Logging and Observability Platform

## Context
- Logs, metrics, and traces
- Operational monitoring

## Recommended Architecture
- Log agents
- Message queue
- Search and indexing
- Dashboards and alerts

## Non-functional Considerations
- High ingestion rate
- Fast query performance
- Retention management

## Typical Components
- Log Agents
- Log Ingestion Service
- Search Engine
- Dashboard UI
- Alert Manager
